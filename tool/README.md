# Tooling

## Spotify API sync

`spotify-openapi.yaml` is a snapshot of the [Spotify Web API OpenAPI spec](https://developer.spotify.com/reference/web-api/open-api-schema.yaml), exactly as Spotify publishes it.

The [Spotify API sync workflow](../.github/workflows/spotify-api-sync.yml) runs every Monday (or manually via "Run workflow") and compares the published spec against this snapshot. If it changed, the workflow opens a PR on the `chore/spotify-api-sync` branch with the updated snapshot and a changelog generated by [oasdiff](https://github.com/oasdiff/oasdiff) - so the PR doubles as a to-do list of what to adapt in the library. An already open sync PR gets updated instead of opening a new one.

The workflow needs "Allow GitHub Actions to create and approve pull requests" to be enabled under Settings → Actions → General → Workflow permissions.

Note that CI doesn't run automatically on PRs created by the workflow.
